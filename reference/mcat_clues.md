# MCAT clues for the alphabet game

A data frame with one MCAT clue for each letter of the alphabet.

## Usage

``` r
mcat_clues
```

## Format

A data frame with 26 rows and 4 variables:

- letter:

  The letter the answer is tied to.

- mode:

  Either "starts" (answer begins with the letter) or "contains" (answer
  includes the letter).

- clue:

  The clue shown to the player.

- answer:

  The correct answer.
